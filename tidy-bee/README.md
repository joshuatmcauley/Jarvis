# The Tidy Bee

A 2026-style marketing site for a Downpatrick domestic cleaning business.

## Run locally

```bash
cd tidy-bee
npm install
npm run dev
```

Open the printed local URL. Production build:

To put it on a Raspberry Pi with your own domain, see [deploy/HOSTING.md](deploy/HOSTING.md).

To host it in the cloud (Vercel / GitHub Pages, no Pi), see [deploy/CLOUD.md](deploy/CLOUD.md).

```bash
npm run build
npm run preview
```
