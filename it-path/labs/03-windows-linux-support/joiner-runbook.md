# New-starter / joiner runbook (draft)

Use this in interviews as “this is how I would not miss a step.” Adjust to whatever stack the employer uses (AD, Entra, Google, MDM).

**Never** put real customer names or passwords here.

## Before day one

- [ ] Account created in the directory
- [ ] Licence / M365 or email mailbox
- [ ] MFA method registered (or break-glass process known)
- [ ] Groups for file shares / VPN / wifi / printer
- [ ] Hardware: laptop imaged, disk encryption, asset tag
- [ ] Ticket raised and assigned

## Day one (first 30–60 min)

- [ ] Confirm identity (manager present if that is policy)
- [ ] Sign-in works, password change if temporary
- [ ] Email send/receive test
- [ ] VPN or always-on access test **off** corporate LAN if that is the design
- [ ] Printer / scan to email
- [ ] Line-of-business app icon + a test transaction that is allowed
- [ ] Who to call; how to log a ticket

## If it fails

Walk [TROUBLESHOOTING.md](../../TROUBLESHOOTING.md). Write the ticket like a diary row.
