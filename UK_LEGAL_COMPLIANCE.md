## ✅ Pre-Installation Legal Checklist

### Camera Installation - Road Traffic Act 1988 & Highway Code

- [ ] **Front Camera Positioning** (if installed)
  - [ ] Maximum 40mm intrusion into windscreen wiper area
  - [ ] Behind rear-view mirror (center-top position)
  - [ ] Does not obstruct driver's view of the road
  - [ ] Mounted with secure adhesive or bracket
  
- [ ] **Rear Camera**
  - [ ] Provides clear view behind vehicle
  - [ ] Waterproof (IP67 minimum rating)
  - [ ] Wiring protected and not exposed to weather
  
- [ ] **Side Cameras**
  - [ ] Do not protrude dangerously from vehicle
  - [ ] Securely mounted (won't fall off at speed)
  - [ ] If replacing mirrors: Must comply with ECE Regulation 46.04

### Display Screen - Road Vehicles (Construction and Use) Regulations 1986

- [ ] **Screen Content While Driving**
  - [ ] Navigation/maps: ✅ ALLOWED
  - [ ] Vehicle status/gauges: ✅ ALLOWED
  - [ ] Reversing camera: ✅ ALLOWED
  - [ ] Video playback: ❌ NOT ALLOWED (must be disabled while moving)
  - [ ] Implement speed lockout: Videos only play when parked
  
- [ ] **Physical Installation**
  - [ ] Securely mounted (no movement during driving)
  - [ ] Does not obstruct driver's view
  - [ ] Does not obstruct passenger airbag deployment
  - [ ] All cables hidden and secured

### Data Protection - UK GDPR & Data (Use and Access) Act 2025

- [ ] **Recording Public Spaces**
  - [ ] Personal use exemption applies (no commercial use)
  - [ ] 30-day rolling storage (auto-delete old footage)
  - [ ] Clear signage if recording passengers (optional for personal car)
  
- [ ] **Data Storage**
  - [ ] Footage stored securely (encrypted recommended)
  - [ ] Be prepared to provide footage to police if requested
  - [ ] Don't upload footage to social media without blurring faces/plates

### Electrical Safety

- [ ] **Wiring Standards**
  - [ ] Inline fuse (10A) on 12V line
  - [ ] Proper gauge wire (16AWG minimum for 5A draw)
  - [ ] All connections soldered or crimp connectors (no twist-and-tape)
  - [ ] Wiring routed away from hot surfaces (exhaust, engine)
  
- [ ] **Grounding**
  - [ ] Proper ground to vehicle chassis
  - [ ] No ground loops (audio interference)

## 🔧 MOT Compliance Checklist

### Pre-MOT System Check

- [ ] **Screen & Display**
  - [ ] Set to navigation/home screen (not video)
  - [ ] Brightness appropriate (not distracting)
  - [ ] No cracks or damage to screen
  
- [ ] **Wiring**
  - [ ] All cables hidden (not visible from driver's seat)
  - [ ] No exposed wires
  - [ ] No loose connections
  
- [ ] **Dashboard Warning Lights**
  - [ ] If screen displays speed: Must accurately read from ECU/CAN bus
  - [ ] Original warning lights still functional (ABS, airbag, engine, oil)
  - [ ] If you've hidden original instrument cluster: MUST replicate all MIL (Malfunction Indicator Lamps)
  
- [ ] **Steering Wheel Controls** (if integrated)
  - [ ] Hazard lights button works
  - [ ] Horn works
  - [ ] Cruise control works (if equipped)
  
- [ ] **Reversing Camera** (if equipped from factory)
  - [ ] Must remain functional
  - [ ] Provides adequate view
  - [ ] Activates when reverse gear engaged
  
- [ ] **General Roadworthiness**
  - [ ] Installation hasn't interfered with:
    - [ ] Steering
    - [ ] Brakes
    - [ ] Lights
    - [ ] Seat belts
    - [ ] Airbags

### MOT Tester Interaction

**What to say**:
> "I've installed an aftermarket infotainment system with a reversing camera. All original safety systems remain functional and the installation is secure. The screen only displays navigation and vehicle information while driving."

**What NOT to say**:
- Don't mention video playback capability
- Don't demonstrate touchscreen during test (looks like distraction)

### Common MOT Failures for Aftermarket Systems

| Failure Reason | How to Avoid |
|----------------|--------------|
| Obscured driver view | Position screen low and centered |
| Exposed wiring | Hide all cables behind trim |
| Non-functional warning lights | Keep original cluster OR replicate via CAN bus |
| Insecure mounting | Use proper brackets, not double-sided tape |
| Video screen visible to driver | Disable video playback when moving |

## 🚗 Insurance Compliance

### Before Installation

- [ ] **Check Policy Wording**
  - [ ] Review "modifications" section
  - [ ] Check if cosmetic mods need declaring
  - [ ] Verify if electronics mods need declaring

### After Installation

- [ ] **Declare Modification**
  - [ ] Call insurer or use online portal
  - [ ] Describe as: "Aftermarket infotainment system with reversing camera"
  - [ ] Provide installation receipts (if professionally installed)
  - [ ] Mention it's a **safety feature** (reversing camera reduces accidents)
  
- [ ] **Expected Outcomes**
  - ✅ No premium increase (or small £10-20 increase)
  - ✅ Possible discount (some insurers discount for dash cams)
  - ⚠️ If premium increases significantly: Shop around

### Insurance Benefits to Mention

- Reversing camera reduces parking accidents
- Dash cam provides evidence in disputes
- GPS tracking may deter theft
- OBD-II monitoring detects maintenance issues early

### Software Compliance

- [ ] **Video Playback Lockout**
  - [ ] Implement speed-based lockout (video disabled >5mph)
  - [ ] OR GPS-based lockout (video disabled when moving)
  - [ ] Test regularly to ensure it works
  
- [ ] **Distraction Prevention**
  - [ ] Large touch targets (easy to hit while driving)
  - [ ] Voice control for primary functions
  - [ ] Auto-dim screen at night
  - [ ] Minimize on-screen animations while driving

## 🚨 What If You Get Stopped by Police?

### During Traffic Stop

**Stay Calm**: Aftermarket infotainment is legal

**If Asked About the Screen**:
> "It's an aftermarket navigation and reversing camera system, officer. It only displays maps and vehicle information while driving. It complies with the Road Vehicles regulations - no video playback while moving."

**If They Want to Check**:
- [ ] Demonstrate it only shows navigation
- [ ] Show reversing camera activates when in reverse
- [ ] Explain power cuts off with ignition (not a distraction when parked)

**What They Can't Do**:
- Can't confiscate unless they suspect it's interfering with driving safety
- Can't issue fine for having an aftermarket screen (if legally compliant)

**What They Can Do**:
- Issue Construction & Use prohibition if screen obstructs view
- Issue fine (£100) if video playback visible while driving
- Issue careless driving fine if you're distracted by it

### Your Rights

- Legal to have aftermarket screen ✅
- Legal to have dash cam/cameras ✅
- Legal to replace factory radio ✅
- Must not obstruct view ⚠️
- Must not display video while driving ⚠️

## ⚖️ Relevant Legislation

### Primary Laws

1. **Road Traffic Act 1988**
   - Section 40A: Using vehicle in dangerous condition
   - Section 41D: Breach of construction and use requirements

2. **Road Vehicles (Construction and Use) Regulations 1986**
   - Regulation 109: View to the front (windscreen obstruction)
   - Regulation 98: Video screens visible to driver

3. **Road Vehicles (Construction and Use) (Amendment) (No. 2) Regulations 2024**
   - Camera-monitor systems as mirror alternatives (ECE 46.04)
   - In force: April 1, 2025

4. **UK GDPR & Data Protection Act 2018**
   - Personal use exemption for dash cams
   - Data retention and subject access rights

5. **Data (Use and Access) Act 2025**
   - Video telematics provisions
   - Recognised legitimate interests

### Standards & Codes

- **Highway Code**: Rule 30 (windscreen obstruction)
- **ECE Regulation 46.04**: Camera-monitor systems
- **BS AU 178**: Road vehicles - Visibility requirements
