# JARVIS memory

This folder is the long-term brain for the daily iPhone Cursor agent.

| File | Purpose |
| --- | --- |
| `agent.json` | Pinned cloud agent id + URL (open this, don't start a new one) |
| `PROFILE.md` | Who Josh is and what JARVIS hardware he has |
| `facts.md` | Decisions and facts that should survive forever |
| `journal/YYYY-MM-DD.md` | What happened that day |
| `inbox/` | Voice notes waiting to be filed |

Chat transcripts disappear when a VM recycles. These files do not, as long as they are committed.
