# The Tidy Bee

A 2026-style marketing site for a Downpatrick domestic cleaning business.

## Run locally

```bash
cd tidy-bee
npm install
npm run dev
```

Open the printed local URL. Production build:

```bash
npm run build
npm run preview
```

## Content notes

Prices, extras, laundry, service areas, and the 10% first-clean offer come from The Tidy Bee Facebook flyers. WhatsApp is `07874 463679` (`wa.me/447874463679`). Facebook Messenger can be added when the page URL is confirmed.

Prices are “from” figures and may vary with property size and condition.
